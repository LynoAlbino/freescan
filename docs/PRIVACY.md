# FreeScan privacy policy

Effective 24 November 2026.

FreeScan processes photographs, PDF files, extracted text and editing state on your own device. The application does not upload document content. It has no analytics, telemetry, advertisements, account registration, cloud storage, external OCR service or paid API.

The app requests camera permission when you open the scanner. It does not request microphone or location access. Torch and focus controls are used only when the camera reports support. Camera tracks are stopped when the scanner closes.

Documents are stored in this browser's IndexedDB. Application assets and downloaded OCR languages are stored in browser caches. Theme and interface language preferences are stored locally. The app does not encrypt document storage. Other users of the same device/browser profile may be able to access it.

Initial installation, application updates and language downloads request static files from the hosting origin. Your host may receive normal connection metadata, such as an IP address. These asset requests contain no document data. Self-hosting is supported. No external CDNs are contacted during normal operation.

Sharing invokes the operating system's share sheet when supported; the user chooses the destination. Once you explicitly share or download a document, its subsequent handling is controlled by that destination or your device. Backups are unencrypted ZIP archives; store them securely.

Deleting a document removes it from the local library. Settings → Clear all local data removes documents, drafts, app preferences, application caches and OCR caches for FreeScan. Temporary object URLs are revoked. Browser/OS backups and already downloaded files are outside the app's control.

Clearing browser storage, storage pressure, private browsing or uninstalling may remove local files. Export important documents and backups. No server copy exists to recover lost data.
